# ADR-0003: 미결 사항

## 상태
미결 (2026-09-11). 각 항목은 기본값으로 동작하며, 사용자가 결정하면 이 문서를 갱신하고 해당 ADR 을 분리한다.

## (a) 봉투 구성 — 미결
- 기본값: `식료품`, `생필품`, `기타` 세 봉투로 분리.
- 변경 방법: `Config.envelopes` 값(콤마 구분)을 바꾸면 봇 버튼·Budgets 시드·상태 회신이 모두 따라간다.
- 결정 필요: 외식을 식료품에서 분리할지, 아이 관련 지출을 별도 봉투로 둘지.

## (b) 월말 잔액 처리 — 미결
- 기본값: `reset` (남은 잔액을 다음 달로 넘기지 않음).
- 변경 방법: `Budgets.carryover` 를 봉투별로 `carry` 로 바꾸면 `monthlyOpen()` 이 전월 잔액을 다음 달 amount 에 가산한다.
- 결정 필요: 어떤 봉투에 carry 를 적용할지.

## (c) 유류비 — 미결
- 기본값: `fixed` (Recurring R06, 월 예상 $250, tolerance 30%).
- 변경 방법: 사용자가 결정하면 R06 을 `active=N` 으로 바꾸고 Merchants 의 `주유/gas` 를 `variable` + 봉투로 재지정한다.
- 결정 필요: 주유를 고정비 예상치로 관리할지, 유동비 봉투로 매번 기록할지.
