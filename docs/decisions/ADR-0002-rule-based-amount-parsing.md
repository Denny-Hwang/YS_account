# ADR-0002: 금액·날짜·통화 추출은 규칙 기반만

## 상태
채택 (2026-09-11)

## 결정
Telegram 메시지에서 금액·날짜·통화를 뽑는 로직은 정규식과 고정 규칙만 사용한다. LLM 은 P6 이후 분류(봉투·카테고리) 보조에만 검토한다.

## 근거
1. 돈 액수는 틀리면 곧바로 원장 오류가 된다. 규칙 기반은 결정적이라 같은 입력에 항상 같은 결과를 주고, Node 단위 테스트로 회귀를 잡을 수 있다.
2. 외부 API 호출이 없으므로 비용·지연·장애가 없고, 거래 원문이 제3자에게 나가지 않는다.
3. 애매한 입력(금액 두 개, 미래 날짜)은 `confidence: low` 로 표시해 사용자가 확인하게 하면 충분하다.
