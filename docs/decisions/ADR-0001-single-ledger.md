# ADR-0001: 월별 탭 대신 단일 원장

## 상태
채택 (2026-09-11)

## 결정
모든 거래를 `Transactions` 탭 하나에 append-only 로 기록한다. 월별 탭을 만들지 않고, 월별 화면은 `Monthly_View` 수식으로만 재현한다.

## 근거
1. 봇·웹앱·트리거가 "이번 달 탭이 어디인지" 찾을 필요가 없어 코드가 단순해지고, 월이 바뀌어도 탭 생성 실패 같은 경계 오류가 없다.
2. 기간 집계(최근 12개월, 카테고리 추이, 부채·목표 진행률)가 SUMIFS/QUERY 한 번으로 끝나고, 탭을 순회하는 스크립트가 필요 없다.
3. soft delete 와 `updated_at/updated_by` 감사 추적이 한 표에서 일관되게 유지되어, 웹앱 편집과 시트 직접 편집이 충돌하지 않는다.
