# P5 — Monthly_View / Dashboard 수식

```
목표: 시트 안에서 지금 쓰던 월별 화면을 수식으로 재현한다. 데이터는 넣지 않는다.

읽을 파일: CLAUDE.md, docs/SHEET_SCHEMA.md.

작업:
1. `apps-script/src/Views.js` — `buildMonthlyView()`: Monthly_View 탭을 지우고 다시 그린다.
   - B1: 월 선택 셀 (YYYY-MM, 데이터 유효성 = Transactions 의 date 에서 유도한 월 목록).
   - 블록 1 수입: type=income 인 행 QUERY, 합계.
   - 블록 2 고정비: Recurring 기준으로 name, expected_amount, 실제(그 달 confirmed/expected amount_usd), 편차, status.
   - 블록 3 유동비 봉투: envelope 별 Budgets.amount, 실행(SUMIFS), 잔액, 남은 일수(오늘 기준), 일일 가용액.
   - 블록 4 카테고리 비중: category 별 합계와 비중(%).
   - 블록 5 원장: 그 달 status≠deleted 행 전부 QUERY (date, type, category, merchant, amount_usd, memo, source).
   모든 수식은 문자열로 setFormula. 하드코딩 숫자 금지. 헤더는 한국어.
2. `buildDashboard()`: 최근 12개월 수입/지출 합계 표 + Debts 잔액 표 + Goals 진행률(목표액 대비 Assets 최신 합).
   차트 1개(월별 수입·지출 막대)를 코드로 삽입.
3. Setup.js 의 runSetupAll 끝에 두 함수 호출 추가.
4. `claude/prompts/P5.md` 저장, STATUS.md 갱신 (P5 완료, 다음 = P6 마이그레이션 또는 P7 웹앱 — 사용자 결정 대기).

검증: `node --check` 통과. `grep -c "setFormula" apps-script/src/Views.js` 가 10 이상.
수식 문자열 안에 `Transactions!` 참조가 탭 이름 상수(SHEETS)에서 오는지 확인.

종료 조건: 커밋 "P5: Monthly_View 와 Dashboard 수식" 후 멈춘다.
```

## 구현 메모
- 행 목록은 `QUERY` 대신 `FILTER`, 집계는 `SUMIFS` 대신 `SUMPRODUCT` 를 쓴다.
  `Transactions.date` 는 Apps Script 가 문자열로 쓰지만 Google Sheets 가 날짜값으로 바꾸는 경우가 있어
  한 열에 텍스트와 날짜가 섞일 수 있다. `LEFT(TEXT(date,"yyyy-mm-dd"),7)` 로 비교하면 두 형태 모두
  정확히 걸러진다. QUERY 의 `where` 절은 혼합 열에서 행을 조용히 빠뜨린다.
- 탭·열 참조는 전부 `colRange(SHEETS.X, 'header')`, `colCell(...)` 이 SHEETS 상수에서 만든다.
  수식 문자열에 `Transactions!` 같은 리터럴을 쓰지 않으므로 헤더가 바뀌어도 참조가 따라간다.
- 블록 1·2·3·4 는 각각 20/20/10/20 행을 쓴다. 확장 결과가 아래 블록을 덮지 않도록 경계를 고정했다.
  정의가 늘어나면 `MV_ROWS` 를 조정한다.
- `sheet.clear()` 만 쓰고 `clearContents`/`deleteRow` 는 쓰지 않는다(Golden Rule 3).
  Monthly_View 와 Dashboard 는 수식 전용 탭이라 원장 데이터에 영향이 없다.
