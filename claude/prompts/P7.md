# P7 — 웹앱 MVP (Vite + React PWA, GitHub Pages)

```
목표: "오늘 쓸 수 있는 돈" 과 원장 편집을 브라우저에서 한다. 백엔드는 만들지 않는다.

작업:
1. `webapp/` 에 Vite + React + TypeScript 앱을 만든다. 의존성은 react, react-dom 뿐.
2. 인증: Google Identity Services 토큰 클라이언트. scope 는 spreadsheets 하나.
   액세스 토큰은 메모리에만 두고 401 이면 한 번 조용히 갱신한다.
3. 데이터: Sheets API v4 를 직접 호출한다(values:batchGet / append / update).
   열 번호를 코드에 박지 않고 항상 시트의 헤더 행을 읽어 매핑한다.
4. 계산: 예산·파서·분류는 apps-script/src 의 순수 모듈을 그대로 쓴다. 복사하지 않는다.
5. 화면 셋: 오늘 / 원장 / 설정.
6. PWA: manifest + 앱 껍데기만 캐시하는 서비스 워커. 시트 데이터는 캐시하지 않는다.
7. 배포: GitHub Actions 로 GitHub Pages 에 올린다. base 는 저장소 이름에서 만든다.
8. 비밀값: 스프레드시트 ID 와 클라이언트 ID 는 저장소에 두지 않는다.

검증: webapp npm test 통과, npm run build(타입 검사 포함) 통과.

종료 조건: 커밋 "P7: 웹앱 MVP" 후 다음 단계로.
```

## 구현 메모
- **순수 모듈 공유.** `apps-script/src/{Budget,Parser,Classifier}.js` 는 GAS 가 전역 스코프에
  이어 붙이는 ES5 라 `export` 문이 없다. `webapp/scripts/gas-shared.mjs` 의 `toEsm` 이
  최상위 function 이름을 모아 ESM export 를 붙이고, Vite 플러그인이 빌드 때 이를 적용한다.
  같은 변환기를 `webapp/tests/shared-bridge.test.mjs` 가 실제로 불러와 검증하므로
  브리지가 깨지면 빌드 전에 테스트가 먼저 잡는다. 코드를 복사했다면 봇과 웹앱의 계산이 갈라졌을 것이다.
- **비밀값.** 원래 계획은 스프레드시트 ID 를 빌드 환경 변수로 넣는 것이었다. 그러면 ID 가
  번들에 박혀 공개 사이트에 노출된다. 대신 설정 화면에서 받아 `localStorage` 에만 둔다.
  덕분에 배포 워크플로에 비밀값이 하나도 필요 없다. 클라이언트 ID 는 원래 공개 값이라
  선택적으로 Actions 변수로 미리 채울 수 있게 했다.
- **행 번호.** 원장은 append-only + soft delete 라 기존 행의 번호가 변하지 않는다.
  그래서 읽을 때 계산한 행 번호(`_row`)로 그대로 수정 요청을 보낼 수 있다.
- **서비스 워커.** 앱 껍데기만 캐시한다. 잔액은 오래된 값을 보여 주는 것이 아예 안 보이는 것보다 나쁘다.
