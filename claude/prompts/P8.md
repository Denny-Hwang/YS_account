# P8 — 웹앱 확장 (예산·고정비·부채·자산·목표·리포트)

```
목표: P7 의 세 화면 위에 나머지 관리 화면과 리포트를 올린다.

작업:
1. 하단 탭을 오늘/원장/예산/리포트/더보기 다섯 개로 바꾸고, 나머지는 더보기 안에 둔다.
2. 예산: 월별 세부예산 금액과 carryover 를 고친다. 행이 없으면 추가한다.
3. 고정비: Recurring 정의의 예상 금액과 active 를 고치고, 이번 달 확정 여부와 편차를 보여 준다.
4. 부채·자산·목표: 공용 RowSheet 로 추가와 수정을 처리한다.
5. 리포트: 최근 12개월 수입·지출 막대, 선택한 달의 순저축과 카테고리 비중, 최신 자산 합계.
6. 시트 쓰기는 전부 ledger.ts 의 appendTo / patchIn 을 거친다. 열 번호를 코드에 박지 않는다.

검증: npm run build(타입 검사 포함) 통과, 실제 렌더링을 스크린샷으로 확인.

종료 조건: 커밋 "P8: 웹앱 확장 화면" 후 다음 단계로.
```

## 구현 메모
- **차트.** 수입·지출 두 계열은 dataviz 검증기를 통과한 조합을 쓴다.
  밝은 모드 `#2a78d6` / `#eb6834`, 어두운 모드 `#3987e5` / `#d95926`.
  두 모드 모두 명도 대역, 채도 하한, 색각 이상 분리, 정상 시각 분리, 표면 대비를 전부 통과했다.
  검증기 없이 눈으로 고르지 않았다.
- 축은 하나다. 수입과 지출 모두 USD 라 같은 축에 둔다.
- 계열이 둘이라 범례를 항상 띄우고, `표로` 토글로 같은 값을 표로도 읽을 수 있게 했다.
  색만으로 정보를 전달하지 않는다.
- 카테고리 비중은 계열이 하나라 범례가 없다. 막대마다 금액과 비율을 직접 붙였다.
- 막대는 누르면 선택된다. 터치 기기에는 hover 가 없으므로 tap 으로 대신하고,
  선택한 달의 수치는 위쪽 순저축 카드와 아래 카테고리 목록이 함께 보여 준다.
- **공용 RowSheet.** 부채·자산·목표는 필드 목록만 다르고 동작이 같아서 한 컴포넌트로 처리한다.
  탭마다 별도 폼을 만들면 같은 코드가 세 벌 생긴다.
- **자산.** 덮어쓰지 않고 날짜별 스냅샷을 쌓는다. 진행률은 가장 최근 날짜의 합계만 본다.
