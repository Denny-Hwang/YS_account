# P0 — 저장소 뼈대와 문서

```
목표: 빈 저장소를 프로젝트 뼈대로 만든다. 코드는 쓰지 않는다.

작업:
1. 위 (B) 내용으로 `CLAUDE.md` 생성.
2. `.gitignore` 생성: node_modules/, apps-script/.clasp.json, .env, .env.*, *.local, .DS_Store
3. 디렉터리와 빈 자리표시 파일 생성:
   apps-script/src/.gitkeep, apps-script/tests/.gitkeep, webapp/.gitkeep,
   claude/prompts/.gitkeep, claude/routines/.gitkeep, docs/decisions/.gitkeep
4. `docs/ARCHITECTURE.md` 작성 (한국어, 각 항목 5~10줄):
   - 계층: Telegram 봇 / Apps Script / Google Sheet / PWA 웹앱 의 역할과 하지 않는 것
   - 데이터 흐름: 메시지 → doPost → 파서 → 사전 조회 → 기록 → 회신
   - 보안 경계: 시트 공유 = 접근 권한, 웹훅 URL 내 secret 파라미터 + 허용 Telegram ID,
     Script Properties 에만 비밀값, 봇 회신은 유동비 잔액까지만
   - 롤링 일일 가용액 정의: allowance_today = (budget − spent_before_today) / remaining_days_incl_today
5. `docs/SHEET_SCHEMA.md` 작성. 아래 탭과 열을 표로 정확히 기록:
   Transactions: id, date, type(income|expense|transfer), kind(fixed|variable), category, envelope,
     merchant, amount, currency, amount_usd, recurring_id, status(active|expected|confirmed|deleted),
     memo, payer, source(telegram|web|recurring|csv|migration), created_at, updated_at, updated_by
   Recurring: id, name, kind, category, expected_amount, currency, due_day, amount_rule(fixed|income_pct:N),
     tolerance_pct, active, notes
   Budgets: month(YYYY-MM), envelope, amount, carryover(reset|carry)
   Merchants: keyword, type, kind, category, envelope, recurring_id, hit_count, last_used
   Debts: id, name, principal, rate_pct, monthly_payment, remaining_count, currency, notes
   Assets: snapshot_date, account, balance, currency
   Goals: id, horizon(short|mid|long), title, target_amount, deadline, linked_envelope, notes
   Config: key, value  (필수 키: fx_usd_krw, envelopes(콤마구분), default_currency, timezone,
     allowed_telegram_ids(콤마구분), daily_summary_hour, month_start_day)
   Log: timestamp, telegram_id, raw_text, parsed_json, result
   Monthly_View, Dashboard: 수식 전용, 데이터 없음
6. `docs/decisions/ADR-0001-single-ledger.md` (월별 탭 대신 단일 원장, 근거 3줄),
   `docs/decisions/ADR-0002-rule-based-amount-parsing.md` (금액은 규칙 기반만),
   `docs/decisions/ADR-0003-open-decisions.md` — 미결 항목을 "미결" 로 기록:
     (a) 세부예산 구성: 기본값 [식료품, 생필품, 기타] 분리, Config.envelopes 로 변경 가능
     (b) 월말 잔액: 기본값 reset, Budgets.carryover 로 세부예산별 변경 가능
     (c) 유류비: 기본값 fixed(Recurring), 사용자 결정 시 variable 로 전환
7. `docs/STATUS.md` 작성: 현재 단계 P0 완료, 다음 할 일 = P1.
8. `claude/routines/resume.md` 작성: STATUS.md 와 git log 를 읽고 다음 할 일부터 시작하는 절차 5줄.
9. 이 프롬프트를 `claude/prompts/P0.md` 로 저장.

검증:
- `find . -type f -not -path './.git/*' | sort` 출력을 보고하고, 위 파일이 모두 있는지 확인.
- `git grep -n "SPREADSHEET_ID\|BOT_TOKEN"` 결과에 실제 값이 없는지 확인 (자리표시 문자열만 허용).

종료 조건: 위 파일 생성 완료 후 커밋 "P0: 저장소 뼈대와 설계 문서" 하고 멈춘다.
```
