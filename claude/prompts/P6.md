# P6 — 기존 월별 탭 → Transactions 이관

```
목표: 옛 가계부의 월별 탭을 단일 원장 Transactions 로 옮긴다. 원본은 읽기만 한다.

읽을 파일: CLAUDE.md, docs/SHEET_SCHEMA.md, apps-script/src/{Config,Sheet,Ledger}.js 의 export 목록.

작업:
1. `apps-script/src/MigrationMap.js` — 순수 모듈.
   - `normalizeLegacyAmount(value, defaultCurrency)` → {amount, currency, negative} 또는 null.
   - `normalizeLegacyDate(value, fallbackMonth)` → 'YYYY-MM-DD' 또는 null.
   - `migRowId(tabName, rowNumber)` → 'mig_<슬러그>_<행번호>'. 멱등성의 근거.
   - `buildTransactionFromRow(sourceRow, map, ctx)` → {status: 'ok'|'blank'|'error', transaction?, reason?}.
   - module.exports 가드. GAS 전역 충돌을 피하려고 내부 헬퍼에는 mig 접두사를 쓴다.
2. `apps-script/src/Migration.js` — GAS 전용.
   - `MIGRATION_MAP` 상수(사용자가 채움): tabs[{name, month}], columns{대상→원본 헤더}, defaults.
   - `previewMigrationSource(tabName)`: 헤더와 첫 세 행을 로그로.
   - `migrateAll()`: 쓰지 않고 보고만. `migrateAllCommit()`: 실제로 append.
   - `migrationReport()`: source=migration 행 수.
   - 원본 탭을 지우거나 고치지 않는다. Transactions 는 append 만 한다.
3. `apps-script/tests/migration-map.test.js` — 금액·날짜 표기, 행 id 고정, 수입/지출 판정,
   KRW 환산, blank/error 분기.
4. docs/SETUP.md 에 P6 절 추가, claude/prompts/P6.md 저장, STATUS.md 갱신.

검증: npm test 전부 통과, node --check 통과, deleteRow/clearContent 없음.

종료 조건: 커밋 "P6: 기존 월별 탭 이관 스크립트" 후 다음 단계로.
```

## 구현 메모
- 원래 계획에서는 "열 매핑은 사용자가 제공" 이었다. 매핑을 코드에 박는 대신 `MIGRATION_MAP` 상수로 빼고
  `previewMigrationSource` 로 원본 헤더를 먼저 보여 주는 방식으로 만들었다. 옛 시트를 보지 않고도
  이관 로직 전체를 완성할 수 있고, 사용자는 헤더 이름만 채우면 된다.
- 멱등성은 `id = mig_<탭>_<행번호>` 로 얻는다. 별도 기록 열이 필요 없고,
  `migrateAllCommit` 을 몇 번 실행해도 같은 원본 행은 한 번만 들어간다.
- `migrateAll()` 이 기본 미리보기다. 쓰기는 이름이 다른 `migrateAllCommit()` 으로만 가능하다.
  이관은 되돌리기 번거로운 작업이라 실수로 한 번에 수백 행이 들어가지 않게 했다.
- Date 셀은 `Migration.js` 가 시트 시간대로 문자열 변환한 뒤 순수 모듈에 넘긴다.
  순수 모듈이 Date 를 직접 다루면 UTC 기준으로 하루가 밀릴 수 있다.
