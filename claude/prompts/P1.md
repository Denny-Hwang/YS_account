# P1 — 시트 스키마 생성 스크립트 (`Setup.js`)

```
목표: Apps Script 함수 `setupSheet()` 한 번 실행으로 SHEET_SCHEMA.md 대로 시트를 만든다.

읽을 파일: CLAUDE.md, docs/SHEET_SCHEMA.md 만.

작업:
1. `apps-script/appsscript.json` 생성: timeZone "America/Los_Angeles", runtimeVersion "V8",
   exceptionLogging "STACKDRIVER", webapp { access: "ANYONE_ANONYMOUS", executeAs: "USER_DEPLOYING" }.
2. `apps-script/.clasp.json.example` 생성: { "scriptId": "<SCRIPT_ID>", "rootDir": "src" }.
3. `apps-script/package.json` 생성: name family-budget-gas, scripts.test = "node --test tests/",
   private true. 의존성 없음.
4. `apps-script/src/Config.js`:
   - `SHEETS` 상수: 탭 이름과 헤더 배열을 SHEET_SCHEMA.md 와 글자 단위로 동일하게 정의.
   - `getConfig(key)`, `getConfigList(key)`: Config 탭에서 읽기, 5분 CacheService 캐시.
   - `getSecret(key)`: PropertiesService.getScriptProperties() 에서 읽기. 없으면 throw.
5. `apps-script/src/Setup.js`:
   - `setupSheet()`: 없는 탭은 생성, 있는 탭은 헤더 행만 검증(불일치 시 throw, 데이터는 건드리지 않음).
     헤더 행 고정(freeze), 굵게. 각 탭에 데이터 유효성(드롭다운): type, kind, status, carryover,
     horizon, currency(USD,KRW), envelope(Config.envelopes 참조 범위).
     Config 탭에 필수 키를 기본값과 함께 삽입(있으면 건너뜀):
       fx_usd_krw=1332, envelopes=식료품,생필품,기타, default_currency=USD,
       timezone=America/Los_Angeles, allowed_telegram_ids=(빈값), daily_summary_hour=7, month_start_day=1
   - `seedRecurring()`: Recurring 탭이 비어 있을 때만 다음 행 삽입 (금액은 사용자가 수정):
       R01 하우스 렌트 fixed 주거비 2100 USD 1 fixed 0
       R02 관리비 fixed 주거비 207 USD 1 fixed 15
       R03 어린이집 fixed 교육비 350 USD 4 fixed 0
       R04 통신비 fixed 통신비 80 USD 1 fixed 10
       R05 월 구독료 fixed 구독 173 USD 1 fixed 0
       R06 유류비 fixed 유류비 250 USD 1 fixed 30
       R07 주일헌금 fixed 헌금 160 USD 1 fixed 0
       R08 십일조 fixed 십일조 (빈값) USD 26 income_pct:7 0
       R09 부채상환 fixed 부채상환 (빈값) USD 15 fixed 0
   - `seedMerchants()`: Merchants 탭이 비어 있을 때만: 코스트코/costco→식료품, 세이프웨이/safeway→식료품,
     밤부마켓→식료품, 주유/gas→R06, 관리비→R02, 통신비→R04, 레슨→income 영주 레슨.
   - `seedBudgets(month)`: 해당 월의 Budgets 행이 없으면 Config.envelopes 마다 amount 0, carryover reset 삽입.
   - `runSetupAll()`: 위 네 개 순서대로 호출. 멱등이어야 한다(두 번 실행해도 결과 동일).
6. `apps-script/src/Sheet.js`: 공통 헬퍼
   - `getSheet(name)`, `readAll(name)` → 헤더 키 객체 배열, `appendRow(name, obj)` (헤더 순서로 정렬),
     `findRowById(name, id)` → 행 번호, `updateRowById(name, id, patch)` (updated_at 자동),
     `newId(prefix)` → prefix + '_' + Utilities.getUuid().slice(0,8), `nowIso()`.
7. `docs/SETUP.md` 작성 (성주가 따라 할 수동 절차):
   a. clasp 사용 시: `.clasp.json.example` 복사 → scriptId 기입 → `clasp push`.
      미사용 시: src/*.js 를 Apps Script 편집기에 같은 파일명으로 붙여넣기.
   b. Script Properties 등록: SPREADSHEET_ID, BOT_TOKEN, WEBHOOK_SECRET (P3 에서 사용).
   c. 편집기에서 `runSetupAll` 실행 → 권한 승인 → 시트 탭 생성 확인.
   d. Config.allowed_telegram_ids 에 두 사람 ID 입력, Budgets 금액 입력, Recurring 금액 확인.
8. 이 프롬프트를 `claude/prompts/P1.md` 로 저장. STATUS.md 갱신.

검증:
- `node --check apps-script/src/*.js` 모두 통과.
- `grep -c "SpreadsheetApp" apps-script/src/Config.js apps-script/src/Setup.js apps-script/src/Sheet.js`
  가 각각 1 이상 (GAS 전용 파일임을 확인).
- SHEET_SCHEMA.md 의 각 탭 헤더와 Config.js 의 SHEETS 헤더를 한 줄씩 대조해 보고.

종료 조건: 커밋 "P1: 시트 스키마 setup 스크립트" 후 멈춘다. 실제 시트 실행은 사용자가 SETUP.md 로 진행.
```
