# P4 — 고정비 자동 기장·아침 요약·월 마감 (시간 트리거)

```
목표: 사람이 아무것도 안 해도 매월 고정비가 잡히고, 매일 아침 요약이 오고, 월말에 정리가 된다.

읽을 파일: CLAUDE.md, apps-script/src/{Config,Sheet,Ledger,Budget,Telegram}.js 의 export 목록.

작업:
1. `apps-script/src/Recurring.js`
   - `postMonthlyRecurring(yyyyMm?)`: Recurring.active=Y 각 행에 대해 그 달 status∈{expected,confirmed} 행이
     없을 때만 Transactions 에 append: date = 그 달 due_day, kind fixed, status expected,
     amount = expected_amount (amount_rule 이 income_pct:N 이면 그 달 income 합 × N/100, 아직 0 이면 0),
     source recurring, recurring_id 지정. 멱등.
   - `recomputeIncomePct(yyyyMm)`: income_pct 항목을 그 달 수입 합으로 재계산 (status 가 expected 인 경우만).
   - `unconfirmedRecurring(yyyyMm)`: 아직 expected 인 항목 목록.
2. `apps-script/src/Jobs.js`
   - `dailySummary()`: 어제 유동비 지출 합, 봉투별 formatStatusLine, 오늘이 due_day 인 Recurring 항목 안내
     ("오늘 관리비 예상 $207 — 실제 금액 다르면 '관리비 212' 로 보내주세요"). allowed_telegram_ids 전원에게 전송.
   - `monthlyOpen()`: 매월 Config.month_start_day 에 실행. seedBudgets(이번 달)(전월 금액 복사, carryover=carry 인
     봉투는 전월 잔액을 amount 에 가산) → postMonthlyRecurring(이번 달) → 요약 전송.
   - `monthlyClose()`: 말일 21시. 봉투별 예산·실행·잔액, 고정비 예상 대비 실제 편차(tolerance 초과만),
     미확인 Recurring 목록을 한 메시지로 전송. 데이터는 바꾸지 않는다.
   - `installTriggers()`: 기존 이 프로젝트 트리거 전부 삭제 후 dailySummary(매일 Config.daily_summary_hour),
     monthlyOpen(매월 1일 06시), monthlyClose(매월 28일 21시 실행 후 말일 여부를 코드에서 판정) 등록. 멱등.
3. Webhook.js 의 수입 기록 경로에서 `recomputeIncomePct(이번 달)` 호출 한 줄 추가.
4. `docs/SETUP.md` 에 P4 절 추가: `installTriggers` 실행, 트리거 화면 확인, `dailySummary` 수동 실행으로 메시지 수신 확인.
5. `claude/prompts/P4.md` 저장, STATUS.md 갱신.

검증:
- `node --check` 통과, `npm test` 통과.
- `grep -n "ScriptApp.newTrigger" apps-script/src/Jobs.js` 가 정확히 3곳.
- postMonthlyRecurring 멱등성: 코드에서 "이미 있으면 건너뜀" 조건을 인용해 보고.

종료 조건: 커밋 "P4: 고정비 자동 기장, 아침 요약, 월 마감" 후 멈춘다.
```

## 구현 메모
- `monthlyClose` 트리거는 "매월 28일 21시" 대신 **매일 21시**로 등록하고, 말일 여부를 함수 안에서 판정한다.
  Apps Script 의 `onMonthDay()` 는 고정된 날짜만 받는데 말일은 28/29/30/31 로 달라지므로,
  28일 트리거만으로는 2월을 제외한 모든 달에서 말일 보고를 놓친다.
  매일 21시 트리거 + 말일 판정이면 모든 달에서 정확히 말일에 한 번만 동작하고,
  `ScriptApp.newTrigger` 호출 수도 3개로 유지된다. 말일이 아니면 메시지를 보내지 않는다.
- `monthlyOpen` 의 트리거 일자는 `Config.month_start_day` 를 읽는다(기본 1일).
- 전월 예산 복사와 carry 이월은 `openMonthBudgets(month)` 가 담당하고, 전월에 없던 봉투는
  기존 `seedBudgets(month)` 가 amount 0 으로 채운다.
- `recomputeIncomePct` 호출은 Webhook.js 의 두 수입 경로(사전 매칭 기록, 버튼 분류 기록)에 각각 한 줄씩 넣었다.
