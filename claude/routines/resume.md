# resume.md — 세션 재개 절차

1. `docs/STATUS.md` 를 읽어 "현재 단계"와 "다음 할 일"을 확인한다.
2. `git log --oneline -20` 으로 마지막 커밋이 STATUS.md 의 완료 이력과 일치하는지 확인한다. 불일치하면 STATUS.md 를 먼저 바로잡는다.
3. "다음 할 일"에 적힌 단계의 프롬프트(`claude/prompts/P<n>.md`, 없으면 사용자가 제공한 원문)를 열어 "읽을 파일" 목록에 있는 파일만 읽는다.
4. 그 단계의 작업 항목을 순서대로 수행하고, 프롬프트의 검증 명령을 실행해 결과를 보고한다.
5. 종료 조건에 도달하면 STATUS.md 를 갱신하고 지정된 메시지로 커밋한 뒤 멈춘다. 다음 단계로 자동 진행하지 않는다.
